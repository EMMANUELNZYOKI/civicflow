# CivicFlow — Short project report

## Chosen problem and need
CivicFlow is a community service navigator. Many residents know they need help but do not know which organization to contact, whether they qualify, or what to do first. The site provides one clear, searchable starting point for health, learning, essentials, and safety services.

## How each webpage addresses the problem
- **Home page:** introduces the problem and the three-step Discover–Compare–Connect journey.
- **About page:** explains the system purpose, client/server architecture, hosting options, and emerging web trends.
- **Services page:** presents service cards, categories, search, a dynamic filter, hyperlinks, and a comparison table.
- **Gallery page:** demonstrates images/graphics, HTML5 audio, and HTML5 video to communicate the human side of community support.
- **Contact page:** provides an accessible request form. JavaScript validates required fields and email format, then gives dynamic feedback.

## Programming concepts applied
HTML5 semantic elements structure the site. CSS creates a responsive layout for desktop and mobile devices. JavaScript uses variables, arrays, functions, conditionals, loops, DOM methods, event listeners, and form validation. The page navigation demonstrates interconnected hyperlinks. The site also demonstrates lists, tables, forms, images/graphics, audio, and video.

The client is the visitor’s browser. It renders the interface and runs JavaScript. In a production version, an application server would receive contact requests, query a database of providers, and expose web APIs for live service availability, maps, and opening hours.

## Hosting and trends
Shared hosting is a low-cost option for this static prototype. An application server is appropriate when the system adds authentication, database storage, APIs, and server-side form processing. A dedicated server offers maximum control and predictable resources for a large, high-traffic deployment.

The project demonstrates responsive design and progressive enhancement. It could evolve into a single-page application with dynamic API requests. Web API integration could bring in maps, emergency alerts, live opening hours, and provider updates.
